# 采集CD管理——冷漠

作者：冷漠

当前版本：1.0.0

这个脚本用来跑原神的材料、怪物路线。填好要采什么、各要多少，它会自己找已订阅的路线，按顺序跑，顺手把每条路线的刷新时间记下来。目标采够了就停；不填目标就把所有路线跑一遍，直到都进 CD。

## 装到 BetterGI

把脚本文件夹整个放到：

```text
C:\BetterGI\User\JsScript\GatherCombatCDManager
```

然后打开 BetterGI 的「JS 脚本」页，刷新一下列表，选「采集CD管理——冷漠」运行。

第一次运行会在脚本目录里生成 `采集CD管理配置文件\`。里面有 `panel_settings.json` 和 `record\<账号UID>\`，放的是面板配置和路线 CD。换电脑或者把脚本发给别人时，这个文件夹不用带。

## 面板怎么开

默认按 **F7** 打开配置面板，不限制当前焦点在哪个窗口。快捷键可以在面板里改：点一下输入框，直接按你想用的键就行。小键盘数字、Insert、方向键这些也都认。

现在没有屏幕上的「配置」按钮，只能用快捷键开面板。

在 BetterGI 里点「运行」后，默认会先弹面板。想跳过，就在面板里把「运行前显示本面板」改成「不显示」。

面板下面有三个按钮：

- 「保存配置」：只保存，不跑。
- 「开始执行」：保存并按新配置开始。已经在跑的时候点，会按新配置重新开始。
- 「结束脚本」：和按 F10 一样，脚本会结束。

右上角的「×」只是关面板，不结束脚本。运行前关掉就是这次不跑；跑图中关掉，当前这条路线会中断，不记 CD，也不扣数量，然后继续后面的流程。

跑图中按 F7 开面板时，脚本会先把当前剩余数量写进配置，再显示面板。面板里看到的就是最新数量。开面板会把当前路线判为中断，这条不记 CD、不扣数量，免得暂停后接着跑出问题。

## 采集目标怎么写

一行写完，像这样：

```text
沙脂蛹*100+史莱姆凝液*50+丘丘王*3
```

`+` 分隔不同目标，中文的 `＋`、`×` 和字母 `x` 也认。目标可以写材料名、怪物名，也可以写怪物掉落物名。写怪物名时，捡到它任意一种掉落物都算一个；写掉落物名时，脚本会去找会掉这个东西的怪物路线。

不写数量就是不限量，比如 `沙脂蛹+甜甜花*10`。写 `0` 就是跳过这个目标。

整行空着，就按顺序跑所有已订阅路线，不限数量，直到全部进 CD。

名称有重复时可以写完整一点的路径，比如 `地方特产\须弥\沙脂蛹`。`晶核` 这种常用叫法也能认成晶蝶。完整的名称和掉落物在 `可选材料名单.txt` 里，每次运行会重新生成。

目标采完后默认结束。想接着把剩下的路线跑完，勾上「目标采集完成后继续按顺序跑剩余路线」。

同一个材料订了好几套路线时，面板里会列出来：

```text
薄荷  [2 组]
  ☑ 全收集@Tool_tingsu
  ☐ 通用无战斗版
```

不勾就只跑第一组。勾一个跑一个，勾多个按顺序跑。目标后面写 `#all` 可以临时把这个材料的全部版本都跑一遍，比如 `沙脂蛹#all*100`。

## 数量怎么扣

不看路线文件名里的 `-N个`，也不算背包前后差多少。跑图时会识别游戏里的 F 拾取提示：认出 F 图标，再读旁边的物品名，命中当前目标就按 F 捡，剩余数量减一。同一条提示短时间内重复出现只算一次。

途中看到别的可捡东西也会顺手捡，白名单是已订阅的材料和怪物掉落物。

剩余数量先放在内存里，这几个时候写回配置：

- 打开配置面板之前；
- 脚本结束、按 F10、点「结束脚本」、到停跑时间。

数量减到 0 的目标会从「采集目标」里删掉，下次不会再去采。

如果 `assets/F_Dialogue.png` 被删了或改坏了，或者某个怪物在 `assets/怪物掉落.txt` 里没有掉落记录，就只能按「跑完一条路线算 1 个」来记。

## CD 怎么算

| 类型 | 刷新时间 |
| --- | --- |
| 地方特产 | 46 小时 |
| 矿物 | 铁块等每天 0 点；白铁块等每 2 天 0 点；水晶块等每 3 天 0 点（魔晶矿不支持） |
| 食材与炼金 | 按物品表，12 小时 / 每天 0 点 / 每 3 天 0 点等 |
| 敌人与魔物 | 普通怪 12 小时；精英怪每天 4 点 |

每跑完一条路线，会在这个账号的 `record\<账号>\` 里写下次刷新时间。想强制重跑，就把对应记录文件删掉。

敌人的刷新规则在 `assets/敌人刷新规则.txt`。格式是 `刷新机制: 关键词 关键词...`，按怪物名包含匹配，从上往下，先命中的生效，`默认` 那行兜底。

路线卡死、脱离、重试、放弃这些交给 BetterGI 自己的路径逻辑，脚本不另外设超时。路线自己报错时，脚本跳过这条、记上 CD，继续跑后面的。

## 队伍和 UID

采集队伍有三支，按 主 → 备选 → 第三支 的顺序找当前路线需要的角色，三支都没有就跳过这条路线。战斗队伍只给「敌人与魔物」里的纯战斗路线用，采集路线全程用采集队伍。

切队伍之前会先传到须弥·道成林七天神像脱战，传送失败就用道成林神像的坐标兜底。联机模式不切队伍。

食材打动物、抓晶蝶这类路线，会优先挑带「不惊动小动物」角色的队伍。只换队伍，不改行走位。

脚本必须读到 9 位账号 UID 才会开始跑。单人模式读右下角，联机非房主读好友资料那块。读不到就每 2 秒重试，一直重试到读到为止，不会拿「默认账号」顶替。

## 悬浮窗和配置文件

跑图时有个进度悬浮窗，上面显示已运行时间和北京时间，中间是当前路线，下面是目标名和剩余数量。位置、大小在面板里按 X/Y 百分比和大小百分比调，改完立刻生效。没有进度条，也没有路线耗时预估。

配置在 `采集CD管理配置文件\panel_settings.json`，是普通文本，坏了删掉让脚本重新生成就行。配置和记录会一直留着，重启 BetterGI 不会重置。

日志只留启动摘要、目标、UID、路线扫描结果、目标完成汇总、CD 跳过、错误和警告。长时间挂机不会一直刷。
