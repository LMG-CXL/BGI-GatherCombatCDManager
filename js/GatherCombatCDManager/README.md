# 采集CD管理——冷漠

作者：冷漠

一个给 BetterGI 用的 JavaScript 采集脚本：按采集目标自动找路线、记录每条路线的刷新 CD、按实际拾取扣减剩余数量；不填目标时按顺序跑完所有已订阅路线，直到全部进入 CD。

## 安装

把整个脚本文件夹放到 BetterGI 的脚本目录：

```text
C:\BetterGI\User\JsScript\GatherCombatCDManager
```

在 BetterGI 的「JS 脚本」页面刷新脚本列表，选中「采集CD管理——冷漠」运行即可。

脚本第一次运行会在自己的目录下创建：

```text
采集CD管理配置文件\
├── panel_settings.json    面板配置
└── record\<账号UID>\      各账号的路线 CD 记录
```

这个文件夹属于本机运行数据，换电脑或发给别人时可以不带。

## 运行流程

1. 在 BetterGI 里点「运行」。
2. 默认先在游戏画面里弹出配置面板；也可以在面板里把「运行前显示本面板」改成「不显示」，直接用已保存的配置开始。
3. 点「开始执行」保存配置并开始跑图；点「保存配置」只保存不运行。
4. 面板右上角「×」只关闭面板，不结束脚本。运行前关掉等于本次不运行；执行中关掉会中断当前路线（该条不记 CD、不扣数量），脚本继续后面的流程。
5. 跑图过程中按配置的快捷键打开面板，会先写入当前剩余数量，再显示面板；正在执行的这条路线按中断处理。
6. 点「结束脚本」或按 F10 结束脚本，剩余数量会回写配置。

## 配置面板快捷键

- 默认 **F7**，可在面板的「打开配置面板快捷键」里修改，点输入框后直接按键盘即可录入。
- 全局键盘钩子，不要求游戏窗口在前台；建议和 BetterGI 的暂停快捷键设成同一个。
- 支持 F1–F12、字母、主键盘数字、小键盘数字与运算键、Insert/Delete/Home/End/PageUp/PageDown、方向键、Esc/Tab/空格/回车/退格、CapsLock/NumLock、PrintScreen/ScrollLock/Pause、Shift/Ctrl/Alt/Win 和常见符号键。
- 只保留快捷键打开方式，不再显示任何悬浮「配置」按钮。

## 采集目标怎么填

```text
沙脂蛹*100+史莱姆凝液*50+丘丘王*3
```

- 格式为 `名称*数量`，多个目标用 `+` 连接；中文 `＋`、`×`、字母 `x` 也能识别。
- 整行留空：按顺序执行全部已订阅路线，不限数量，直到所有路线都进入 CD。
- 某一项不写数量表示不限量，如 `沙脂蛹+甜甜花*10`；写 `0` 表示跳过该项。
- 名称可以是材料名、怪物名或怪物掉落物名。写怪物名时，拾到它的任意掉落物都算 1 个；写掉落物名时，脚本会自动找到对应怪物路线。
- 名称不唯一时可以写更完整的路径，例如 `地方特产\须弥\沙脂蛹`；也支持部分别名，如 `晶核` 对应晶蝶。
- 具体名称、掉落物和版本清单见脚本目录的 `可选材料名单.txt`，每次运行会刷新。
- 目标采够后默认结束；想继续把剩余路线跑完，勾选「目标采集完成后继续按顺序跑剩余路线」。

## 多版本路线

同一个材料订阅了多套路线时，面板的「多版本路线选择」会把版本列出来：

```text
薄荷  [2 组]
  ☑ 全收集@Tool_tingsu
  ☐ 通用无战斗版
```

- 不勾选：只跑第一组。
- 勾一个：只跑该版本；勾多个：按顺序依次执行。
- 目标里写 `沙脂蛹#all*100`，可临时强制跑该物品的全部版本。
- 版本目录下的更深子目录算在同一版本内，不会拆成多个选项。
- 勾选结果保存在 `采集CD管理配置文件\panel_settings.json` 的 `selectRoute_物品名` 中。
- 面板顶部可以按名称搜索；「清空全部勾选」等于全部恢复为只跑第一组。

## 数量怎么扣

脚本不使用路线文件名里的 `-N个`，也不靠背包前后差值，而是识别跑图时的 F 拾取提示：

1. 截取游戏画面，在 F 图标区域做模板匹配（`assets/F_Dialogue.png`）。
2. 识别到 F 图标后，OCR 同一行的物品名。
3. 命中当前目标时按 `F` 拾取，剩余数量减 1。
4. 同一条提示在短时间内重复出现时只记一次。
5. 途中识别到的其它可拾取物品也会顺手捡走，白名单为已订阅材料与怪物掉落物。

剩余数量在内存中累计：

- 打开配置面板前写回一次，保证面板显示最新数量；
- 脚本结束、按 F10、点「结束脚本」、到达停跑时间时写回；
- 数量为 0 的目标会从 `采集目标` 中移除，下次不会重复采。

如果 `assets/F_Dialogue.png` 缺失或被修改，或者怪物在 `assets/怪物掉落.txt` 中没有掉落记录，则退回「完成一条路线计 1」。

## CD 规则

| 类别 | 刷新机制 |
| --- | --- |
| 地方特产 | 46 小时 |
| 矿物 | 铁块等每天 0 点；白铁块等每 2 天 0 点；水晶块等每 3 天 0 点（魔晶矿不支持） |
| 食材与炼金 | 按物品表：12 小时 / 每天 0 点 / 每 3 天 0 点等 |
| 敌人与魔物 | 普通怪 12 小时；精英怪每天 4 点 |

- 每跑完一条路线，写入该路线的下次刷新时间，记录在 `record\<账号>\` 下。
- 想强制重跑某条路线，删掉对应的记录文件即可。
- 敌人刷新规则在 `assets/敌人刷新规则.txt`，格式为 `刷新机制: 关键词 关键词...`，按怪物名包含匹配，从上到下先命中生效，`默认` 行兜底。

## 路线执行与卡死

- 路线按文件名顺序执行，同一物品的多条路线按 `01-…`、`02-…` 的顺序跑。
- 路线卡死、脱离、重试、放弃由 BetterGI 自带的路径逻辑处理，脚本不额外做路径超时。
- 路线自身抛出异常时，脚本跳过该路线并记录 CD，继续后面的路线。

## 队伍

- 三支采集队伍按 主 → 备选 → 第三支 的顺序，寻找路线所需角色；三支都缺就跳过该路线。
- 战斗队伍只给「敌人与魔物」分类的纯战斗路线使用；地方特产、矿物、食材与炼金路线全程使用采集队伍。
- 切换队伍前会先传送到须弥·道成林七天神像脱战；传送失败时使用道成林神像坐标兜底。
- 联机模式不切换队伍。
- 食材打动物、抓晶蝶两类路线会优先选择带「不惊动小动物」角色的队伍；只切队伍，不改变行走位。

## 账号 UID

- 脚本必须读取到 9 位账号 UID 才会执行路线。
- 单人模式读取游戏右下角 UID；联机非房主读取好友资料区域的 UID。
- 读不到就每 2 秒重试，一直重试到读到为止，不会使用「默认账号」代替。

## 悬浮窗

跑图时显示采集进度悬浮窗：

- 顶部：已运行时间、当前北京时间；
- 中间：当前执行的路线；
- 下方：目标名称和剩余数量。

位置与大小在配置面板里按 X/Y 百分比（0–100）和大小（0–100）设置，实时生效；无进度条和路线耗时预估。

## 其它

- 配置保存在 `采集CD管理配置文件\panel_settings.json`，是可读文本；文件损坏时删掉即可，脚本会自动生成默认配置。
- 配置和记录长期保留，不会因重启 BetterGI 重置。
- 脚本日志只保留启动摘要、目标、UID、扫描结果、目标完成汇总、CD 跳过、错误和警告，避免长时间挂机产生大量日志。
